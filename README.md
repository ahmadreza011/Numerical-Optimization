# Numerical-Optimization
Implementations of the computer assignments for the Numerical Optimization course: (all algorithms optimized in a way to need the minimum possible number of function, gradient, and Hessian evaluations)

- HW1: Implementing Golden Search Section (GSS)
- HW4: Implementing Steepest Descent, Newton algorithms and using GSS for the line search step
- HW7: Implementing Steepest Descent, Newton algorithms and using Strong Wolfe conditions for the line search step
- HW8: Implementing BFGS algorithm
